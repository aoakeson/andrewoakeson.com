# Selected AI projects

These are projects from the resume. Describe them as engineering. Do not invent revenue, bookings, or user counts.

## Always-on operations agent, 2026 to present

Claude Code, MCP, and Python. Andrew designed it and runs it daily for business partners and two outside clients, a real-estate brokerage and a cabin-rental company. It drafts email and guest messages, writes pricing briefs, does research, and helps with web development. More than 20 Discord channels are isolated from each other. Outbound messages require a person's approval. Each channel's sender address is locked in code and checked with Google OAuth. Nearly 40 scheduled jobs run with persistent memory and lifecycle hooks.

## Content agent, Sep 2026 to present

A scheduled headless Claude Code and Supabase agent researches, writes, and scores its own drafts, then hands translation into five languages to parallel subagents. It publishes about one sourced article a day to a production hospitality site, 40+ posts since September 2026. The score is a quality signal. Publishing does not require a passing score.

## Janae, 2026

AI assistant MVP. Next.js, React, TypeScript, the Vercel AI SDK, and Supabase. About 40 Zod-typed tools, streamed execution, an eight-step cap, structured outputs, idempotent writes, and PostgreSQL row-level security. Useful as a compact example of a typed tool-calling app. It is an MVP.

## Duck Creek Village Inn, 2026

Astro and TypeScript booking site. One availability API over two booking providers, with calendar and pricing checks, Cloudflare caching, and a shared quota across Worker instances.

## Mama Cabins, 2025 to 2026

Hardened a GPT-4o mini cabin-search parser with deterministic dates, field coercion, amenity allowlists, and a regex fallback so a sentence becomes search filters.

## PixStay, 2025

Gemini image analysis, JSON-mode prompt rewriting, and multi-image editing on Supabase Edge Functions, plus authenticated HD-export jobs that check credits.

## Elite Home Selling, 2026

Natural-language property search with the OpenAI Responses API and strict JSON Schema. Deterministic checks on location and numbers, a selective model fallback, timeouts, and caching.

## TrackingTime, 2026

Seven TypeScript and Zod MCP tools for projects, tasks, and time entries. Credentials stay in encrypted storage. A Codex skill checks for overlapping entries.
